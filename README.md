# বাজার দর — BazarDor

**BazarDor (বাজার দর)** is a modern web application for checking the latest prices of everyday essential products in Bangladesh. Users can browse products by category, compare price changes, view market-based pricing information, and securely manage their profiles.

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- DaisyUI
- Hero UI
- Better Auth
- MongoDB Atlas

## Key Features

### 1. Daily Market Price Tracking

Users can view current prices of essential products along with price-change indicators showing whether prices have increased, decreased, or remained unchanged.

### 2. Category-Based Product Browsing

Products can be browsed by categories such as rice, vegetables, fish, meat, and other everyday essentials. Category pages also provide sorting by default price order, low-to-high, and high-to-low.

### 3. Detailed Product & Market Information

Each product has a dedicated details page showing minimum, maximum, and average prices along with market-based pricing information from different markets.

### 4. Secure Authentication & Protected Routes

BazarDor uses **Better Auth** for email/password authentication as well as Google and GitHub social login. Protected pages require users to sign in before accessing them.

### 5. User Profile Management

Authenticated users can view their profile information, navigate to a dedicated update page, change their name, and securely sign out of the application.
